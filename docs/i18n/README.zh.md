## ✨ 功能特色

| | |
|---|---|
| 🏙️ **14 座城市指南** | 东京、京都、大阪、奈良、广岛、横滨、箱根、日光、金泽、札幌、福冈、神户、长崎、冲绳 —— 各有独立视觉与实用提示。 |
| 🗺️ **地图、路线与季节** | 互动目的地地图、示例行程、最佳出行季与节日亮点。 |
| 🖼️ **相册** | 可筛选旅行摄影：画质（缩略图 / 中等 / 原图）与灯箱。 |
| 🧰 **旅行工具** | 预算、行李清单、汇率、时钟、税费、JR Pass、票价估算与紧急电话。 |
| 🚆 **交通要点** | IC 卡、新干线基础，以及 JR / 铁路官方资源入口。 |
| 🎲 **日本趣味冷知识** | 每次随机一条，多语言提供。 |
| 🌐 **多语言** | 英语、日本語、简体中文（含法律页）。 |
| ⚙️ **个性化** | 语言、单位（℃/°F、公里/英里）、主题与动效偏好 —— 保存在本机。 |
| ♿️ **动画：完整 / 减弱 / 关闭** | 三级动效，并遵循系统「减少动态效果」。 |
| 📱 **移动端友好** | 响应式布局与流畅交互。 |
| 🔒 **隐私与条款** | 站内[隐私政策](../../privacy.html)与[使用条款](../../terms.html)。 |
| 🔗 **官方资源** | 指向 JNTO 等官方参考，便于出发前核对。 |
