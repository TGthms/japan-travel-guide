## ✨ 機能

| | |
|---|---|
| 🏙️ **14都市ガイド** | 東京・京都・大阪・奈良・広島・横浜・箱根・日光・金沢・札幌・福岡・神戸・長崎・沖縄。それぞれ独自のデザインと実用ヒント。 |
| 🗺️ **地図・ルート・季節** | インタラクティブな地図、サンプル行程、ベストシーズン、祭りのハイライト。 |
| 🖼️ **フォトギャラリー** | 絞り込み可能な写真。画質（サムネイル／中／フル）とライトボックス。 |
| 🧰 **旅行ツール** | 予算、パッキング、為替、時計、税、JRパス、運賃目安、緊急番号。 |
| 🚆 **交通の基礎** | ICカード、新幹線の考え方、公式 JR／鉄道リソースへの案内。 |
| 🎲 **日本おもしろ豆知識** | シャッフルで1件ずつ。各言語でトリビアを用意。 |
| 🌐 **多言語** | 英語・日本語・简体中文（リーガルページ含む）。 |
| ⚙️ **パーソナライズ** | 言語、単位（℃/°F、km/mi）、テーマ、モーション設定を端末に保存。 |
| ♿️ **アニメ：フル／控えめ／オフ** | アクセシビリティ重視の3段階。OS の「動きを減らす」に対応。 |
| 📱 **モバイル向け** | レスポンシブレイアウトと軽快な操作。 |
| 🔒 **プライバシーと規約** | [プライバシーポリシー](../../privacy.html) と [利用規約](../../terms.html)。 |
| 🔗 **公式リソース** | JNTO など公式情報へのリンクで再確認しやすく。 |
